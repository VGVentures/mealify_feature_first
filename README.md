# Mealify, Brian Egan style.

This app is my attempt to follow the best practices in the VGE docs. I have
tried to adhere as closely as possible to those docs and the best practices
contained within, with my own flavor thrown in here and there. The purpose of
this exercise is to ensure I fully understand the current best practices
recommended by VGV, as well as so I can make informed recommendations for
improvement.
